## pwt-panel.parquet

Country-year panel of core Penn World Table variables for Brazil, Germany, Spain and the United States.

- Recipe: `recipes/pwt_panel/`
- Inputs: `raw/pwt110_bra_deu_esp_usa.csv`

Steps:

1. Reshape the wide export (one column per year) into one row per country, variable and year. (`01_reshape_long.py`)
2. Keep eight core variables: three measures of GDP, population, employment, hours worked, human capital and TFP. (`02_keep_core_variables.py`)
3. Spread the variables into columns, giving one row per country and year. (`03_pivot_to_panel.py`)

| Column | Type |
|---|---|
| iso | string |
| country | string |
| year | integer |
| rgdpe | number |
| rgdpo | number |
| rgdpna | number |
| pop | number |
| emp | number |
| avh | number |
| hc | number |
| rtfpna | number |

## gdp-per-capita.parquet

GDP per capita, its annual growth, and its level relative to the United States.

- Recipe: `recipes/gdp_per_capita/`
- Inputs: `useful-views/pwt-panel.parquet`

Steps:

1. Compute GDP per capita (rgdpe / pop, in 2021 US$), its annual growth in percent (from rgdpna / pop, the series PWT recommends for growth over time), and its level relative to the United States in the same year. (`01_derive_measures.py`)

| Column | Type |
|---|---|

| country | string |
| year | integer |
| gdp_per_capita | integer |
| growth_pct | number |
| relative_to_usa | number |
